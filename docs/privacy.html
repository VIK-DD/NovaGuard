Privacy Policy

This policy covers the NovaGuard Discord bot, dashboard and website operated by VIK & CloudMedia. NovaGuard has no advertising, does not sell personal data and currently uses no third-party analytics.

1. Information NovaGuard Processes

NovaGuard processes Discord user, server, channel and role IDs; dashboard profile and server-access data; server configuration; feature state such as XP, voice minutes, economy balances, warnings, reminders, ticket metadata and giveaway entries; and security records for dashboard actions.

2. Message Content

Messages are inspected in real time for AutoMod and meaningful-message XP. If a server enables Discord logging, deleted or edited message excerpts may be posted to its selected log channel. NovaGuard does not maintain its own archive of ordinary message history. A question submitted with /ask is sent to Anthropic when the optional AI feature is enabled.

3. Storage and Retention

Operational data is self-hosted in SQLite and JSON storage. OAuth state expires after 10 minutes, dashboard sessions after 7 days, and dashboard audit events after 90 days. Server configuration and feature state remain while needed for the selected features or until deletion is requested. The newest 10 local full backups are retained; default off-site windows are 90 days for full backups and 60 days for per-server exports.

4. Essential Cookies and Browser Storage

The site uses only first-party cookies needed for security or a requested access flow: ng_state (10 minutes), ng_session (7 days or logout), ng_gate (2 hours) and ng_preview (up to 12 hours). No advertising or analytics cookie is set, so there is no non-essential cookie choice to accept. Browser storage remembers the selected theme and a public status snapshot; it is not used to identify someone across websites.

5. Third-Party Services

Discord hosts communities and provides OAuth data; Cloudflare hosts and protects the website; GitHub provides repository data when enabled; and Anthropic processes /ask text when AI is enabled. Each provider handles the information it receives under its own privacy policy. NovaGuard shares data only to operate the service or an optional integration chosen by the server operator.

6. Access, Export and Deletion

A server administrator can run /config export for that server's settings, levels, economy and voice records. Logging out revokes the active Discord OAuth token and removes the dashboard session. Depending on local law, people may also request access, correction, deletion, restriction or objection.

7. Security

Dashboard OAuth tokens are encrypted at rest, session identifiers are hashed in the database, changes are access-controlled and audited, and production traffic uses HTTPS. No transmission or storage method is completely secure.

8. Contact

Start a privacy request through the NovaGuard repository or the operator's GitHub profile. Do not post personal data in a public issue; arrange a private channel first, and never share passwords or tokens. Identity or server authority may be verified before a request is completed.
